# CT 病例切分工具 — 操作说明

## 一、整体流程

```
原始录屏数据 ──▶ 自动切分 ──▶ 结果(时间表+截图报告) ──▶ 人工核对修正
  (AI读片原数据)    (脚本)        (case切分工具\结果)      (你看报告)
```

一句话：脚本读医生的鼠标日志，找出"双击打开病例"的 60 个时刻，切成 60 段，并生成带截图的网页供你核对。

## 二、文件结构

```
annotation_segments\
└── case切分工具\
    ├── 启动切分工具.bat      ← 双击启动（入口）
    ├── segment_app.py        ← 图形界面
    ├── segment_cases.py      ← 切分脚本（命令行）
    ├── visualize_cases.py    ← 截图报告脚本
    └── 结果\
        ├── _index.html            ← 总索引（先看这个）
        └── <参与者>_cases.csv     ← 切分时间表（正式结果）
            <参与者>_cases.json    ← 同上（机器可读，含参数）
            <参与者>_report.html   ← 截图报告（人工核对用）
```

## 三、操作步骤

1. 双击 `启动切分工具.bat`，弹出图形界面，一张表列出 18 个参与者。
2. 点「① 运行切分」→ 自动计算每个参与者的 case 数和分组结构，填进表格（目标 `60 = [20,20,20]`）。
3. 点「② 生成截图报告」→ 给每个 case 生成双击瞬间截图，完成后自动打开总索引。
4. 看 `结果\_index.html` → 逐参与者点「打开」，核对每个 case 的截图是否正确（相邻两张图应是不同 CT 病例）。
5. （可选）人工修正 → 发现切错的，直接用 `_cases.csv` 改时间，或用 `annotation_player.py` 对照视频微调。

## 四、怎么读结果表

| 列 | 含义 |
|---|---|
| 参与者 | 编号 |
| case 数 | 检出多少个病例边界 |
| 分组 | 三组各多少个，目标 [20,20,20] |
| 状态 | ✓完美 / 接近 / 偏高(多切了) / 偏低(漏切了) |

`_cases.csv` 每行一个 case：
- `order`：顺序
- `start_ts`：打开时刻（墙钟时间）
- `duration_sec`：时长（到下一个 case 打开为止）
- `open_x / open_y`：双击坐标
- `start_video_sec`：视频相对秒数

## 五、切分原理

医生在病例列表（Patient Name 列）双击打开病例，且每 20 个病例换一种病、换病时列表回到顶部重新滚动。脚本据此：

1. **双击检测**：两次左键点击间隔 <500ms、位移 <50px。
2. **补双击合并**：同一行 3 秒内重复双击算一次。
3. **x 带定位**：自动找病例列表所在列（可能在左也可能在右）。
4. **y 锯齿链**：利用「相邻 case 的 y 递增 10~80px，换病时 y 大幅回跳」过滤误双击。
5. **分组校验**：结果应为 3 组 × 20 = 60。

## 六、高级用法（命令行，一般用不到）

```
python segment_cases.py "参与者目录"        # 切分单个参与者
  --step-lo 10 --step-hi 80   # 锯齿链 y 步进范围
  --reset-max -60             # 翻页回跳阈值
  --dt-max 500 --dist-max 50  # 双击判定阈值
  --no-xband                  # 关闭 x 带筛选
  --show                      # 打印全部双击明细
```
