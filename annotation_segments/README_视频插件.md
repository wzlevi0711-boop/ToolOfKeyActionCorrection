# 标注事件核对播放器（annotation_player.py）操作说明

## 一、它是干什么的

一个图形界面播放器：加载「已检测出的标注/删除事件」+「眼动录屏视频」，让你逐条播放核对、标记对错、补充漏检，最后导出正式的核对表格。

> 与 case切分工具的区别：
> - **本播放器**：核对医生在 CT 图像上的「标注动作 / 删除动作」事件（已有 `annotation_events.csv`）。
> - **case切分工具**：把整段录屏按「双击打开病例」切成 60 个 case 片段。

## 二、运行

```
python annotation_player.py
```

依赖 PySide6（已装）。启动后会自动加载 `events\annotation_events.csv`。

## 三、界面布局

| 区域 | 说明 |
|---|---|
| 顶栏 | 加载视频 / 自动定位视频 / 加载CSV / 参与者下拉 / 播放 / 上一下事件 / 倍速 |
| 左侧 | 视频画面 |
| 右侧 | 事件表（event_id、事件性质、类型、时间、时长、判断、备注） |
| 底部横条 | 时间轴（红=删除动作，蓝=标注动作，绿=手动关键帧） |
| 底部第一行 | 校准 / ✓正确 / ✗错误 / 清除判断 / 备注(回车保存) |
| 底部第二行 | 医生动作下拉(标注/删除) / 关键帧备注 / 添加关键帧 / 删除关键帧 / 导出最终表格 |

## 四、操作步骤

1. 启动后在下拉框选择「参与者」，会自动定位并加载该参与者的录屏视频。
2. 点「播放」或按 ←/→ 跳到每个事件，看视频核对该事件是否为真实标注/删除动作。
3. 核对结果：选中事件后点「✓ 正确」或「✗ 错误」，也可在备注栏填说明（回车保存）。
4. 漏检的事件：把视频拖到发生时刻，选「医生动作」类型、填备注，点「添加关键帧(K)」补充。
5. 时间没对齐时：跳到事件对应画面，点「校准(当前帧=选中事件)」校正偏移。
6. 全部核对完，点「导出最终表格」保存成 CSV。

## 五、快捷键

| 键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 上一个 / 下一个事件 |
| [ / ] | 单帧后退 / 前进 |
| C | 校准（当前帧 = 选中事件） |
| K | 添加关键帧 |
| Delete | 删除关键帧 |
| 1 / 2 / 0 | 标记 正确 / 错误 / 清除判断 |

## 六、数据文件

| 文件 | 作用 |
|---|---|
| `events\annotation_events.csv` | 输入：待核对的事件表 |
| `verification\verification_results.csv` | 输出：每个事件的判断结果(正确/错误+备注) |
| `verification\manual_keyframes.csv` | 输出：人工补充的关键帧 |
| `verification\offset_cache.json` | 视频时间对齐偏移（参与者 → 视频第0帧的unix时间戳） |
| `eye-movement\<参与者>\眼动\<时间戳>\raw.mp4` | 录屏视频 |

事件表列：`event_id`(编号)、`event_type`(annotation=标注/deletion=删除)、`event_ts`(发生时刻)、`duration_sec`(时长)、`distance_px`+`start_x/y`+`end_x/y`(动作起止坐标)、`delete_key`(删除键)。
